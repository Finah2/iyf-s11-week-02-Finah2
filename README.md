## Project Description
Taking the Week 1 portfolio and making it actually look good. Added a full CSS system with custom properties, a luminous green color scheme, Flexbox navigation and footer, CSS Grid for project cards and gallery, and full mobile responsiveness with a hamburger menu.

## Technologies Used
- HTML5
- CSS3
- CSS Custom Properties (variables)
- Flexbox
- CSS Grid
- Google Fonts (Poppins + Open Sans)
- GitHub Pages

## Features
- Color system and typography scale using CSS variables
- Responsive navigation with hamburger menu on mobile
- Hero section with side image on desktop, stacked on mobile
- Project cards in a responsive 1→2→3 column grid
- Photo gallery using CSS Grid
- Magazine-style layout (sidebar + main content)
- Box model practice with visual examples
- Form with sidebar layout on desktop, stacked on mobile
- Multi-column footer
- Hover and focus states on all interactive elements
- Smooth transitions throughout

## Lessons Learned
- CSS variables make it so much easier to keep colors and font sizes consistent — change one line and it updates everywhere
- Flexbox and Grid solve different problems. Flexbox is great for rows and navigation, Grid is better for full page layouts
- Mobile-first means writing the simple single-column layout first, then adding complexity for bigger screens

## Challenges Faced
**Box model confusion:** I kept making elements wider than I wanted because padding was adding to the width. Fixed it with `box-sizing: border-box` on everything.

**Hamburger menu on mobile:** Getting the nav to toggle open and close with just a button and a bit of JavaScript was trickier than expected but satisfying once it worked.
